7. WordPress, Elementor & GHL Integration Standards

Strict container breakout CSS and modular header/footer loading rules.

Astra / Elementor Full-Width Breakout

Add this CSS class to your top-level wrapper inside Elementor HTML widgets to force edge-to-edge full width:

.sm-full-breakout {
  width: 100vw !important;
  position: relative !important;
  left: 50% !important;
  right: 50% !important;
  margin-left: -50vw !important;
  margin-right: -50vw !important;
  box-sizing: border-box !important;
}

GoHighLevel (GHL) Custom Code Wrapper

Wrap all GHL custom funnel code inside this container for full dark mode styling compatibility:

<div class="sm-ghl-wrapper" style="background-color: #0d091a; color: #ffffff; width: 100%;">
  <!-- Page Content Here -->
</div>
